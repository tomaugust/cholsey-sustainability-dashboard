## Decisions
- No new ADR. Astro/TypeScript/Vitest/ESLint/Prettier are exactly what ADR-0002 specifies; no deviation.
- Minor choice not worth an ADR: hand-writing the skeleton instead of fighting `create-astro`'s template flags. The result matches what the scaffolder would have produced for a "minimal + TypeScript" project, just without depending on its template registry being stable/reachable — a small resilience win for a Routine that has no human to unstick it if a scaffolder CLI changes behaviour.
- Minor choice: `astro.config.mjs`'s `site`/`base` are deliberately left unset with a comment, since setting a wrong Pages URL now (before P0.7 confirms the actual one) would need reverting; better to set it once, correctly, in P0.7.
