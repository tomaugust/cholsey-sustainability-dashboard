## Done
- Checked Open questions first (plan §4.7): Q-005, Q-007, Q-010 still open, nothing new to action.
- **Investigated Forest Research's `UK_Ward_Canopy_Cover` dataset properly** (its ArcGIS item metadata via the Hub API, not the "about" page's framing) and found two things this project had previously assumed without checking, both wrong:
  1. It is **not** a single "2020" survey — it's citizen-science i-Tree Canopy data collected ward-by-ward between **2018 and 2022**, each ward with its own `survyear`. Cholsey's own record was surveyed in **2021**.
  2. Cholsey's record uses wardcode **E05009737**, which doesn't exist in the December 2020 ward boundary layer P1.1 fetched (`E05011701`). Queried the December 2018 ward layer directly and confirmed `E05009737` = "Cholsey" there — South Oxfordshire's wards were recoded between those two vintages.
  - **Checked whether the recoding actually matters**: fetched both ward polygons live and computed Cholsey parish's area-share inside each — 99.4% (old ward) vs 100.0% (current ward). Near-identical, so P1.5's existing ward-area-weight (1.0, computed against the current ward) doesn't need correcting. Updated its `flag` column to say what was actually verified, rather than leaving the old "working assumption, see Q-008" text now that it's resolved.
- **Investigated UKCEH's Land Cover Map** (the annual 10m-resolution raster, free for non-commercial use via EIDC). Real finding: it classifies each 10m pixel into one dominant UK BAP Broad Habitat class (e.g. "Broadleaved, Mixed and Yew Woodland"), not a canopy-cover percentage — a materially different measurement that would undercount Cholsey's scattered/garden/hedgerow trees outside contiguous woodland. **Decision (ADR-0006)**: keep Forest Research as metric 1's primary source (matches the spec's actual metric definition); log UKCEH LCM as a documented stretch/backlog item (a genuine annual trend, but not a substitute), not built in Phase 2.
- Built `pipeline/src/cholsey_pipeline/fetch/forest_research_canopy.py`: `fetch_ward_canopy` (live) + `parse_canopy_response` (pure, tested). New fixture with Cholsey's and Wallingford's actual live records. 4 new tests, 82 total passing.
- `config/sources.yaml`: `forest_research_canopy` now has a real, verified `download_url` (found via the ArcGIS item API) and corrected `cadence`/`notes` reflecting the real per-ward survey years; new `ukceh_land_cover_map` entry documents the investigated alternative and why it isn't built.
- **ADR-0006** records the full investigation and decision.
- **Q-008 moved to fully resolved** in STATUS.md's Answered/closed section — it was already `actioned` from an earlier, more provisional response; this entry replaces that with the real investigation's findings.
