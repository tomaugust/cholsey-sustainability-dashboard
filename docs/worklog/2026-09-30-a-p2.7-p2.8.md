- Confirmed live that DLUHC's EPC API has moved: `epc.opendatacommunities.org` now 301-redirects to `get-energy-performance-data.communities.gov.uk`. Read its API technical documentation to get the real `search-certificates/domestic` endpoint (`https://api.get-energy-performance-data.communities.gov.uk/api/domestic/search`), `Authorization: Bearer <token>` auth, JSON response shape, postcode/council/date-range query filters, and pagination (`current_page`/`page_size`, max 5000/page).
- Built the fetcher behind development-plan.md P2.9's required feature flag: `fetch_domestic_certificates` raises `EpcApiKeyMissing` if `api_key` is falsy, so a missing key (this project has never registered one) fails loudly — the pipeline can't mistake "no key" for "no certificates in this postcode."
- **Deliberate exception to the "real fixture values" rule every other Phase 2 fetcher follows**: since no API key exists for this project, a real downloaded response isn't obtainable. The test fixture's field NAMES are verbatim from the live API documentation (verified 2026-09-30, not guessed), but its VALUES are illustrative placeholders — called out explicitly in the module and test docstrings, `config/sources.yaml`'s notes, and here, so this doesn't get mistaken for a real Cholsey EPC result later.
