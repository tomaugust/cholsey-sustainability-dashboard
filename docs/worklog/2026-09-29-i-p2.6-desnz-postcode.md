## Goal

## Done
- Checked Open questions first (plan §4.7): Q-005, Q-007 still open, nothing new to action.
- **Real finding**: P2.1 (2026-09-28) had concluded the most recent postcode-level release findable was from 2020, based on the generic "Postcode level domestic gas and electricity consumption: about the data" methodology page carrying no direct file links. That conclusion was incomplete — postcode-level releases continue under a year-specific slug each year (`postcode-level-electricity-statistics-YYYY`, `postcode-level-gas-statistics-YYYY`), listed on the sub-national electricity/gas consumption data collection pages rather than the methodology page. Verified live through 2024 for both fuels.
- Verified real OX10 2024 figures before writing them into fixtures: electricity 13,168 meters / 51,917,017.12 kWh total; gas 11,078 meters / 127,598,611.87 kWh total.
- Built `pipeline/src/cholsey_pipeline/fetch/desnz_postcode_energy.py`:
  - `find_latest_year` — scrapes the collection page's HTML for the max year under the modern yearly slug pattern, explicitly excluding the older "...-experimental" slug shape (verified a 2013-experimental page exists and must not be picked up as year 2013).
  - `discover_download_url`/`fetch_current_download_url` — same landing-page-scrape pattern as P2.5's `desnz_lsoa_energy` (hash-named GOV.UK assets, re-discovered each run).
  - `parse_postcode_csv` — pure function parsing the real CSV columns (`Outcode, Postcode, Num_meters, Total_cons_kwh, Mean_cons_kwh, Median_cons_kwh`), including the `"All postcodes"` outcode-rollup row.
  - `fetch_postcode_energy` — full live fetch tying discovery + `fetch.http.fetch_file` (P2.2) + parsing together, filtered to requested outcodes.
  - Docstring records the suppression note from spec §3 / plan risk R4: DESNZ suppresses a postcode's row below 5 meters or where the top 2 meters exceed 90% of consumption, so a missing postcode is not necessarily zero — callers needing full coverage should fall back to LSOA-level data (`fetch.desnz_lsoa_energy`) with `flag=parish_estimate`, not treat a gap as zero.
- New fixtures: trimmed real OX10 2024 electricity/gas CSVs (`ox10_electricity_2024_sample.csv`, `ox10_gas_2024_sample.csv`), keeping real rows and the real outcode-total row.
- 9 new tests, 109 total passing.
- `config/sources.yaml`: `desnz_postcode_energy`'s `discovery_rule` corrected to describe the real yearly-page behaviour, `notes` updated with the real verified OX10 figures.
