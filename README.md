# Cholsey Parish Sustainability Dashboard

A public dashboard for Cholsey Parish Council (South Oxfordshire). It tracks the parish's environmental and energy-transition indicators, including tree canopy, green space, domestic energy use, and solar PV and heat pump uptake. It benchmarks them against neighbouring parishes, the district and national averages, and points residents to practical local actions.

**Status:** planning complete, and the build has not started. See [`docs/STATUS.md`](docs/STATUS.md).
